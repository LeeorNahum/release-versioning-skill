# release-versioning-skill

`release-versioning` keeps code, docs, tags, GitHub releases, and release artifacts in sync.

It applies to apps, packages, skills, downloadable builds, firmware binaries, and any project where a versioned artifact is published or consumed.

## Files

- `SKILL.md` contains the release inventory, semver rules, workflow, and artifact rules.
- `AGENTS.md` is the maintenance contract for editing this skill.

## Install

```bash
git submodule add https://github.com/LeeorNahum/release-versioning-skill.git .agents/skills/release-versioning
```
